# aio
## Vision & Core Function
aio (Phase-1 Secure Minimal) is a foundational blockchain infrastructure on Sui designed for secure governance and oracle coordination. It implements elder-gated mode controls (Normal/Degraded/Halted), bond-gated oracle registration, and safe escrow for digital assets, enabling high-integrity on-chain/off-chain data and command flows.

## Technical Stack & Architecture
- **Blockchain:** Sui Move (Smart Contracts)
- **Deployment:** Shell Scripts + Sui CLI
- **Components:** Config & Mode Objects (Governance), Oracle Objects (Bonded), Escrow (Asset Handling)
- **Security:** Elder-gated ActiveRoot sealing and quorum-based off-chain discipline.
