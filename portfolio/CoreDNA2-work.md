# CoreDNA2-work
## Vision & Core Function
CoreDNA2 is a high-performance, AI-driven Brand Intelligence Platform designed to automate brand DNA extraction, competitive analysis, and multi-channel campaign generation. It serves as a central hub for marketing teams to manage affiliates, real-time collaboration, and intelligent automation across a vast array of AI providers.

## Technical Stack & Architecture
- **Frontend**: React (Vite) / TypeScript / Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **AI Integration**: Custom 90+ provider integration (Gemini, OpenAI, Anthropic, etc.)
- **Infrastructure**: Vercel/Self-hosted (Vite optimization)
- **Architecture**: Service-oriented with a focus on real-time data flow and multi-tenant affiliate management.
