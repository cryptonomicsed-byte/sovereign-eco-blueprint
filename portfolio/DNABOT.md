# DNABOT
## Vision & Core Function
DNABOT is an enterprise-hardened AI Marketing Platform that focuses on reliability, cost tracking, and multi-LLM redundancy. It transforms raw data into actionable marketing campaigns while providing rigorous E2E auditing and performance monitoring.

## Technical Stack & Architecture
- **Frontend**: React / TypeScript / Vite
- **Backend**: Node.js / Express (Server.ts)
- **DevOps**: Docker / Docker-Compose / Playwright (E2E testing)
- **AI**: 6+ Enterprise LLM Providers with fallback logic (Gemini fallback)
- **Architecture**: Enterprise-grade with CI/CD readiness and comprehensive monitoring.
