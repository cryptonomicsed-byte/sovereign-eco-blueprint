# GamerWingman
## Vision & Core Function
GamerWingman is a premium Android companion that integrates a local AI (Ollama) into the gaming experience. It tracks cross-platform stats, suggests squad mates, and features a 3D animated avatar that responds to game events and voice commands.

## Technical Stack & Architecture
- **Engine**: Unity 6 LTS (Android focus)
- **Local AI**: Ollama (llama3.2:3b / phi-3:mini)
- **Voice**: Porcupine (Wake word)
- **APIs**: Steam, Xbox Live (MSAL), PSN, Epic Games
- **Architecture**: Hybrid Local/Cloud with local AI inference for privacy and speed.
