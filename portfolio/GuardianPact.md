# GuardianPact
## Vision & Core Function
GuardianPact (SignWise AI) is an AI-powered contract analysis and signature management tool. It uses LLMs to identify "red flags" in legal documents and provides a secure, streamlined signature workflow for non-legal professionals.

## Technical Stack & Architecture
- **Frontend**: React / TypeScript / Vite
- **AI**: Google Gemini (Contract analysis)
- **Storage**: Firebase/Local storage for documents
- **Testing**: Vitest / Playwright
- **Architecture**: Component-driven with specialized legal-analysis services.
