# Kels-Braids
## Vision & Core Function
Kels-Braids is an AI-powered local business platform for hair stylists. It provides a visual gallery, Instagram integration, multi-language support (i18n), and an automated booking system tailored for high-engagement service industries.

## Technical Stack & Architecture
- **Frontend**: React / TypeScript / Vite
- **Features**: i18n, Instagram API, Responsive Design
- **Integration**: AI Studio (Gemini-powered consultation)
- **Architecture**: Single-page application optimized for mobile/local SEO.
