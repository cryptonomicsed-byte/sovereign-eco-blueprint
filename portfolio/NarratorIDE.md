# NarratorIDE
## Vision & Core Function
NarratorIDE is a coding experience amplifier that provides real-time AI narration of the development process. It features 8 language-specific personas (Rust, Go, Python, etc.) to make coding more educational, engaging, and accessible.

## Technical Stack & Architecture
- **Platforms**: Web Interface / VSCode Extension
- **AI**: Multi-LLM (Claude, Ollama, HuggingFace, Grok)
- **Audio**: Text-to-Speech (TTS) engine integration
- **Architecture**: Real-time event bus connecting IDE activities to narrator agents.
