# Nex
## Vision & Core Function
Nex is an Agent-Native Programming Language Runtime (v1.0). It treats agents as first-class citizens, utilizing a graph-based computation system grounded in 7 core axioms. It enables agents to self-modify, coordinate, and spawn sub-agents autonomously.

## Technical Stack & Architecture
- **Runtime**: TypeScript (Node.js/Bun)
- **Protocol**: WebSocket for distributed execution
- **Structure**: Graph-based (Nodes, Links, Guards, Spawns)
- **Philosophy**: Yoruba/Hermetic alignment (7 Axioms)
- **Architecture**: Distributed, agent-native, and self-bootstrapping.
