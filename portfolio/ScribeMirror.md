# ScribeMirror
## Vision & Core Function
ScribeMirror is a comprehensive multi-modal story generation platform that orchestrates over 141 AI providers (including Gemini, Claude, GPT-4, and ElevenLabs). It enables users to create richly illustrated stories with voice narration and cinematic video modes, featuring intelligent provider fallbacks and cost tracking.

## Technical Stack & Architecture
- **Frontend:** React + Vite + TypeScript
- **Services:** Multi-provider LLM abstraction layer, Provider Orchestration Engine
- **Storage:** LocalStorage + Vector DB for persistence
- **Integrations:** Support for 141+ AI providers across text, image, audio, and video modalities.
