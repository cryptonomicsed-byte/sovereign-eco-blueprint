# SwarmIDE2
## Vision & Core Function
SwarmIDE2 is a sophisticated multi-agent AI orchestration platform designed for complex software engineering and problem-solving tasks. It features parallel agent deployment, automated conflict resolution, RLM context compression (reducing token usage by 20-30%), and real-time cost tracking across multiple LLM providers.

## Technical Stack & Architecture
- **Frontend:** React + TypeScript + Vite
- **Testing:** Vitest (111/111 passing)
- **Core Services:** Conflict Resolver, Cost Calculator, RLM Compression, CCA Code Analysis, Ralph Loop (Iterative Execution)
- **Integrations:** Support for 6+ LLM providers, n8n, Langflow, Webhooks, Supabase, and Qdrant.
