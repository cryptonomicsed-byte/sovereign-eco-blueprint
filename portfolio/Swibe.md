# Swibe
## Vision & Core Function
Swibe is a sovereign, agent-native scripting language designed for the birth, governance, and coordination of autonomous AI agents and swarms. It treats cryptographic identity (Ed25519/BIP-39), blockchain state (Sui Move), and LLM reasoning (`think` primitive) as first-class language elements, enabling agents to own their keys, memory, and neural economy.

## Technical Stack & Architecture
- **Compiler:** Multi-target (compiles to JS, Rust, Go, Python, and Sui Move)
- **Runtime:** Secure Node.js `vm` sandbox with resource governing
- **Primitives:** `think` (reasoning), `meta-digital` (high-stakes tasks), `swarm` (coordination)
- **Integrations:** Native support for Ollama (local LLMs), Sui Blockchain (on-chain state), and MCP (Model Context Protocol).
