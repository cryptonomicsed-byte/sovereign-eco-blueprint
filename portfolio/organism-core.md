# organism-core
## Vision & Core Function
The central nervous system of the Technosis Ecosystem. It manages relationships, events, and bridges between specialized "organs" like IfáScript (entropy), Swibe (identity), Omokoda (governance), and ÒSỌ́VM (execution), ensuring the entire organism breathes as a single body.

## Technical Stack & Architecture
- **Core:** Node.js, TypeScript
- **Interoperability:** TS bridges (`birth-ifa-swibe.ts`, `rlm-osovm.ts`)
- **Blockchain:** Sui (intended for ToC/Àṣẹ minting)
- **Execution:** Julia (via OSOVM integration)
