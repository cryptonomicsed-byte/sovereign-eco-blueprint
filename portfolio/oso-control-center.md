# oso-control-center
## Vision & Core Function
A unified command center for the OSO ecosystem. It provides a dictionary-driven dashboard for building, managing, and interacting with the Techgnosis language, ÀṣẹVault VM, and Layer 1/2 witnessing systems.

## Technical Stack & Architecture
- **Backend:** Python, FastAPI, Pydantic
- **Frontend:** HTML/JavaScript Dashboard
- **Storage:** Persistent JSON file storage (`oso_state.json`)
- **Integration:** Python SDK, GitHub Sync, AI Copilot (Ollama/OpenAI)
