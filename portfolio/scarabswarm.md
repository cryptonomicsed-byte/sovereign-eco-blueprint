# scarabswarm
## Vision & Core Function
A high-fidelity simulation engine for autonomous drone racing. It uses verifiable trajectory proofs (Proof-of-Simulation) to enable decentralized racing tournaments and serves as a testbed for LLM-powered flight control.

## Technical Stack & Architecture
- **Engine:** Julia, RigidBodyDynamics.jl (6-DOF physics)
- **Validation:** SHA256 trajectory hashing
- **Pilots:** Naive PID + Ollama-integrated LLM pilots
- **Scoring:** Time, gate accuracy, efficiency, energy
