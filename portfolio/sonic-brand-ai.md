# sonic-brand-ai
## Vision & Core Function
B2B AI platform for automating the creation of auditory brand identities (audio logos, soundscapes). It helps marketing agencies and startups establish unique, high-quality sonic branding using generative audio models.

## Technical Stack & Architecture
- **Core:** Python, LLM (Context generation)
- **Audio Gen:** MusicGen, AudioLDM
- **Post-Processing:** FFmpeg
- **Storage:** Supabase
