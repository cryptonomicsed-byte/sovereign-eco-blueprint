# storyweaver
## Vision & Core Function
An end-to-end publishing platform that uses AI agents (Writer, Editor, Illustrator) to turn prompts into publish-ready eBooks and Audiobooks. It features Kindle Direct Publishing (KDP) integration for instant monetization.

## Technical Stack & Architecture
- **Backend:** Flask, FastAPI
- **Frontend:** Svelte/Vue
- **AI Orchestration:** Ollama (Llama/Gemma), Stable Diffusion (Illustrations)
- **Formatting:** Pandoc, Calibre
