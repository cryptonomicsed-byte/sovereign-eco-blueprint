# stream-providers
## Vision & Core Function
A community-maintained streaming index that powers the `franken-stream` application. It ensures a high-reliability list of movie and series providers, featuring automatic fallbacks and legal alternatives.

## Technical Stack & Architecture
- **Format:** JSON
- **Integration:** Python (franken-stream update system)
- **Maintenance:** GitHub PRs/Issues for provider health
